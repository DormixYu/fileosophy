# Fileosophy 产品需求文档 (PRD)

> 版本：v1.0 | 日期：2026-06-01
> 产品定位：**本地优先的个人项目档案管理与工作流自动化工具**

---

## 一、产品定位

### 1.1 核心价值
Fileosophy 不是团队协作工具，不是看板工具，不是甘特图工具。
**Fileosophy 是一个"项目文件柜"——帮你管理所有项目的文件、状态、进度，并让你能秒速找到任何东西。**

### 1.2 目标用户
- 项目制工作者（咨询顾问、自由职业者、项目经理）
- 每人同时管理 10-100 个项目
- 每个项目有大量文件（10-200 个）
- 核心诉求：**快速创建、快速找到、快速进入工作状态**

### 1.3 一句话描述
> 打开 Fileosophy，3 秒内进入你要工作的项目，一键打开上次的工作现场。

### 2.2 核心理念变化

| 旧设计 | 新设计 |

| 仪表盘是统计卡片 | 首页是**板块入口**，按状态分块，点击即筛选 |
| 甘特图是顶级导航 | 甘特图降级为项目详情子标签 |

| 没有工作会话 | 🎯 记忆并一键恢复工作现场 |

## 三、核心功能详细设计

### 3.1 项目模板系统

**痛点**：新建项目太慢，每次都要填 6 个字段。

**方案**：
- 预设模板：投标、项目、行政、学习、其他（与分类关联）
- 每个模板包含：
  - 编号前缀（如 TB、PJ、XZ）
  - 默认状态（新建时默认"规划中"）
  - 默认看板列结构（待办/进行中/已完成）
  - 默认文件夹子目录（如"01-投标文件"、"02-报价"、"03-合同"）
- 创建流程：选模板 → 输名字 → 完成（2 步）
- 自动在配置的项目根路径下创建项目文件夹

**文件夹扫描导入**：
- 选择一个已有的项目文件夹根目录
- 自动扫描子文件夹，识别项目结构
- 根据文件夹名提取项目名、日期等信息
- 批量创建项目并挂接文件夹

### 3.2 文件标记与备注系统

**痛点**：项目里几十个文件，找不到上次改的关键文件。

**方案**：
- **标记（Star）**：文件右侧一键星标，标记文件在列表置顶
- **备注（Note）**：给文件写一句备注（如"终版合同"、"已审核"）
- **跨项目汇总**：首页底部显示所有标记文件，按项目分组
- **搜索集成**：全局搜索可搜备注内容

**数据模型新增**：
```
FileBookmark:
  - id: number
  - project_id: number
  - file_name: string
  - file_path: string
  - note: string?
  - starred: boolean
  - created_at: string
  - updated_at: string
```

### 3.3 QuickLook 风格文件预览

**痛点**：每次都要用系统应用打开文件，想快速看一眼内容。

**方案**：
- 按空格键或点击预览按钮，弹出 QuickLook 风格预览窗口
- 支持格式：
  - 文本/代码/Markdown（已有）
  - 图片（已有）
  - PDF（新增 — 用系统 WebView 渲染）
  - Word/Excel/PPT（新增 — 转 HTML 后预览，或调用系统 QuickLook）
- 上一张/下一张切换
- macOS 原生 QuickLook 集成（调用 `qlmanage` 命令）

### 3.4 看板深度利用 + 桌面小组件

**痛点**：看板功能存在但利用率低，需要跨项目待办汇总。

**方案**：

#### 3.4.1 看板增强
- 卡片关联文件：一个卡片可关联一个或多个文件
- 卡片关联文件夹：直接打开对应文件夹
- 卡片创建时自动关联项目文件夹
- 待办完成时可选自动归档关联文件

#### 3.4.2 桌面小组件（Widget）
- macOS 桌面小组件（通过 Tauri 插件或独立 Swift 组件）
- 显示：所有项目的待办事项汇总
- 按项目分组，按优先级/截止日期排序
- 每个待办卡片显示：标题 + 关联文件图标
- 点击待办 → 打开 Fileosophy 并定位到该项目
- 点击文件图标 → 直接打开关联文件

### 3.5 工作会话记忆（Work Session）⭐ 杀手级功能

**痛点**：工作一个任务需要同时打开多个文件/网页/应用，每次都要手动找和打开。

**方案**：

#### 3.5.1 会话保存
- 在看板卡片上点击"保存工作会话"
- 自动检测当前打开的：
  - 文件（通过 macOS Accessibility API 或 `lsof`）
  - 应用程序（通过 NSWorkspace）
  - 浏览器标签页（通过 AppleScript/Chrome DevTools Protocol）
- 弹出确认界面，用户可勾选/取消要保存的项目
- 保存为该卡片的工作会话

#### 3.5.2 会话恢复
- 在看板卡片上显示"🎯 恢复工作现场"按钮
- 点击后一键打开所有保存的文件、应用、网页
- 支持编辑会话（添加/移除项目）

#### 3.5.3 桌面小组件集成
- 小组件中每个待办卡片显示"恢复"按钮
- 无需打开主应用即可一键恢复工作现场

**数据模型新增**：
```
WorkSession:
  - id: number
  - card_id: number (关联看板卡片)
  - items: WorkSessionItem[]
  - created_at: string
  - updated_at: string

WorkSessionItem:
  - type: "file" | "app" | "url"
  - path: string (文件路径或应用路径)
  - url: string? (网页 URL)
  - title: string (显示名称)
  - app_name: string? (所属应用名)
```

### 3.6 归档系统

**痛点**：完成的项目和进行中的混在一起。

**方案**：
- 归档操作：选中项目 → 右键/批量操作 → 归档
- 归档后：
  - 项目从主列表消失
  - 项目文件夹被压缩为 .zip（保存到 `.archive/` 目录）
  - 项目元数据保留（不删除数据库记录）
  - 可在"归档库"中浏览和搜索
- 解归档：在归档库中选中 → 解归档 → 自动解压到原路径
- 归档库支持按分类、完成时间、关键词搜索

### 3.7 分类自定义

**痛点**：固定 5 种分类不够用。

**方案**：
- 设置中管理分类列表
- 每个分类：名称、编号前缀、颜色、图标
- 新增/编辑/删除/排序
- 删除分类时已有项目不丢失（归入"未分类"）

### 3.8 ~~共享功能~~ — 已移除

> 共享功能暂时删除，专注个人本地工作流。未来版本可能以线上服务器形式回归。

### 3.9 系统状态栏图标

**方案**：
- macOS 菜单栏常驻图标（Fileosophy logo 缩小版）
- 点击弹出 Popover 菜单：
  - 🔍 快速搜索（输入即搜项目/文件）
  - 📌 标记文件列表（最近 10 个）
  - ✅ 我的待办（跨项目，最近 10 个）
  - 🎯 保存工作会话（检测当前打开的文件/应用/网页）
  - 🔄 恢复工作会话（最近保存的会话列表）
  - ➕ 新建项目
  - ⚙️ 打开设置
  - 📂 打开主窗口

### 3.10 设置增强

**新增设置项**：
- **主题**：暗色 / 浅色 / 跟随系统
- **字体大小**：小 / 中 / 大 / 自定义
- **项目根路径**：设置默认的项目文件夹存放位置
- **默认模板**：选择新建项目时的默认模板
- **全局快捷键**：自定义（新建项目、显示/隐藏窗口、全局搜索、保存工作会话）

## 五、技术方案要点

### 5.1 文件夹扫描导入
- Tauri Rust 端实现递归扫描 + 项目信息推断
- 根据文件夹名模式匹配（日期、编号、关键词）
- 批量导入时提供确认界面

### 5.2 文件预览
- PDF：WebView 原生渲染（Tauri WebView 支持）
- Word/Excel/PPT：使用 `textextract` 或 LibreOffice CLI 转 HTML
- macOS QuickLook：调用 `qlmanage -p <file>` 或 Swift 桥接

### 5.3 桌面小组件
- macOS WidgetKit（Swift）— 独立于主应用
- 通过 App Group 共享数据（SQLite 或 JSON 文件）
- 或通过 Tauri 插件 + macOS StatusBar 实现应用内小组件

### 5.4 工作会话记忆
- macOS：`NSWorkspace.shared.runningApplications` 获取运行中应用
- 文件检测：`lsof` 或 FSEvents 监听
- 浏览器标签：AppleScript 获取 Safari/Chrome 当前标签
- Tauri Rust 端实现进程检测 + 应用启动

### 5.5 归档压缩
- Tauri Rust 端使用 `zip` crate 压缩/解压
- 归档目录：项目根路径下 `.archive/` 隐藏目录
- 保留文件夹结构

## 八、设计原则

### 8.1 视觉风格
- **现代化扁平设计** — 去掉所有多余装饰，极简主义
- **图标扁平化** — 统一使用 Lucide React 线性图标，1.5px 描边
- **色彩克制** — 主色调不超过 2 个（品牌金 + 中性灰），功能色仅用于状态
- **大量留白** — 内容间至少 16-24px 间距，让界面"呼吸"
- **无边框设计** — 用间距和背景色区分区域，减少线条

### 8.2 动效原则
- **所有操作都有动效** — 页面切换、列表入场、卡片悬浮、弹窗开关
- **统一缓动** — `cubic-bezier(0.16, 1, 0.3, 1)` 弹性出场
- **Stagger 入场** — 列表项依次进入，间隔 40-50ms
- **微交互** — hover 上浮 1-2px + 阴影加深，press 缩放 0.98
- **页面切换** — fade + slide 过渡，300ms
- **性能优先** — 只用 transform/opacity 动画，避免 layout 重排

### 8.3 代码策略
- **保留有用的** — Zustand stores、Tauri API 层、路由结构、数据模型
- **删除无用的** — 共享功能代码（SharingPage + 相关组件/store）、旧 UI 样式
- **重写的** — 所有页面组件（新布局+新交互）、CSS 设计系统
